📱 Editar microciclos antiguos (consola) ▾
Ver todos los datos
const d = JSON.parse(localStorage.getItem('b26v2')); console.log(JSON.stringify(d, null, 2));
Editar peso medio de un micro (wHist[0] = M1, [1] = M2...)
const d = JSON.parse(localStorage.getItem('b26v2')); d.wHist[0] = 74.5; localStorage.setItem('b26v2', JSON.stringify(d)); location.reload();
Editar calorías medias de un micro
const d = JSON.parse(localStorage.getItem('b26v2')); d.cHist[0] = 3100; localStorage.setItem('b26v2', JSON.stringify(d)); location.reload();
Editar kilos/reps de un ejercicio en snapshot
const d = JSON.parse(localStorage.getItem('b26v2')); // snapshots[0]=M1, sessions[0]=Empuje1, exercises[0]=Press banca d.snapshots[0].sessions[0].exercises[0].sets[0].kg = 87.5; localStorage.setItem('b26v2', JSON.stringify(d)); location.reload();
Editar micro actual (en curso)
const d = JSON.parse(localStorage.getItem('b26v2')); d.sessions[2].exercises[1].sets[0].kg = 45; localStorage.setItem('b26v2', JSON.stringify(d)); location.reload();

📤 Exportar / importar datos ▾
Archivo con todos los datos de la app. En el iPhone se abre el menú Compartir: elige Guardar en Archivos.
Antes de importar se valida el archivo, se pide confirmación y el estado actual se guarda en b26v2_backup_preimport.
Separador ; y decimal . — Excel lo abre de doble clic; en pandas, sep=';'.
Copia automática del estado anterior al split de 11 días. Solo existe si la migración llegó a ejecutarse.
⚠️ Empezar de cero ▾
Borra el historial de entrenamiento y deja el programa listo para arrancar con pesos nuevos.
Se borra
  • Todos los microciclos archivados (kilos y repeticiones)
  • Las comparaciones de progreso y los saldos por sesión
  • Los kilos guardados en las series actuales
  • El registro diario del microciclo en curso
Se conserva intactoSesiones, ejercicios, número de series, repeticiones prescritas, tipo de serie, RIR, observaciones y grupos musculares. También los ejercicios que hayas añadido tú.
Antes de borrar se guarda una copia completa en b26v2_backup_prereset, restaurable desde la consola. Aun así, exporta el CSV antes si quieres conservar los datos fuera de la app.
